There is no single security appliance or piece of technology that will solve all the network security needs in an organization.

Security appliances can be standalone devices like a router or software tools that are run on a network device.

## routers
while routers are normally used to interconnect networks together, they also have some basic network filtering capabilities

## firewalls
can be used to inspect network packets more deeply and identify malicious behaviour.
- can have more deep inspection if its second generation firewall

## intrusion prevention system
can be used to set traffic inspection signatures with rules that can prevent certain attacks

## Virtual private networks
vpn's can be setup to make connecting to a remote organizations network more secure by creating an encrypted tunnel to it.

## antivirus
uses signature or behaviour based methods to block malicious code from being executed

## other security devices
web or email security appliances, decryption devices and security management devices

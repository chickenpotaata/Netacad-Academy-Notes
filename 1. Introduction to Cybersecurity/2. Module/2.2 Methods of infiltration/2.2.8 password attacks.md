there are many types of password attacks

password spraying
- This technique attempts to gain access to a system by ‘spraying’ a few commonly used passwords across a large number of accounts.
dictionary attacks
- A hacker systematically tries every word in a dictionary or a list of commonly used words as a password in an attempt to break into a password-protected account.
default brute-force attacks
- trying every possible combination of characters on a password
rainbow table attacks
- if you have the hash and you have already precalculated all the brute-forced passwords, you can look up from the rainbow table whether there is a crack for the given hash

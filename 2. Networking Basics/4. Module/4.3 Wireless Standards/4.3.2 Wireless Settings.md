Wireless standard and routers especially have multitude of different settings and characteristics that can be tweaked and changed

some of them are
- network mode
	- Determines the type of technology that must be supported. For example,**802.11b**,**802.11g**,**802.11n** or **Mixed Mode.**
- network name (ssid)
- standard channel
	- Specifies the channel over which communication will occur. By default, this is set to **Auto** to allow the access point (AP) to determine the optimum channel to use.
- ssid broadcast
	- Determines if the SSID will be broadcast to all devices within range
